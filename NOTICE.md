# Preservation and rights notice

This repository preserves and modernizes a recovered copy of the legacy **Pandora Saga Simulator** formerly hosted at:

```text
http://pansaga3.web.fc2.com/simu/
```

## Recovered legacy simulator

The recovered simulator README credits the original author as **z_anthurium**.

The same recovered README explicitly states:

> “Feel free to modify and redistribute.”

No formal license file was found alongside the recovered simulator snapshot. This project does not replace that historical statement or claim exclusive ownership of the recovered legacy simulator. The preserved Legacy Mode remains attributed accordingly.

## Why the distinction matters

A public repository makes source files viewable, but visibility does not transfer ownership of newly authored Remaked material. At the same time, this project must preserve the authorship and permissions of material that existed before the Remaked project. The LICENSE and this NOTICE are intended to make that boundary explicit.
