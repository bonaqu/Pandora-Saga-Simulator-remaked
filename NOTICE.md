# Preservation notice

This repository preserves a recovered copy of the legacy **Pandora Saga Simulator** formerly hosted at:

```text
http://pansaga3.web.fc2.com/simu/
```

## Original authorship

The recovered simulator README credits the original author as **z_anthurium**.

The same recovered README explicitly states:

> “Feel free to modify and redistribute.”

No formal license file was found alongside the recovered simulator snapshot. This project therefore does not invent or replace the original licensing terms; it preserves the attribution and explicit redistribution statement found in the recovered material.
