## 🎮 Что это

**Pandora Saga Simulator Remaked** возвращает к жизни старый браузерный калькулятор персонажа Pandora Saga и постепенно обновляет его интерфейс, не заменяя исходную расчётную логику.

Проект предназначен для игроков, которые хотят экспериментировать с классами, характеристиками, навыками, экипировкой и другими настройками персонажа без зависимости от давно недоступной страницы FC2.

Целевой сервер — [Pandora Saga: Weapons of Balance](https://pandorasaga-os.com/). Пока расчёты выполняет сохранённый движок Legacy 2.00: соответствие текущему балансу сервера нужно сверять отдельно, и точность всех серверных механик ещё не подтверждена.

## ✨ Современный режим

Главная страница открывается в **Modern Mode**:

- обновлённый светлый гибридный интерфейс в духе оригинального зелёного симулятора;
- английский язык по умолчанию;
- сохранены японские и традиционные китайские данные старой версии;
- адаптивная оболочка для обычных мониторов, широких экранов, планшетов и телефонов;
- **поиск экипировки** по текущим совместимым вариантам старого симулятора с фильтрами по названию и уровню;
- **выбор вещи и души в Equipment** в компактном выпадающем списке рядом с полем: характеристики по наведению с задержкой на компьютере, значок информации на телефоне; просмотр не меняет экипировку;
- **поиск Soul** для доступных сокетов и совместимых вариантов из старого симулятора;
- автоматическое локальное сохранение билда и восстановление после обновления страницы;
- **Build Manager** для именованных локальных билдов: сохранить, загрузить, переименовать, скопировать и удалить;
- импорт и экспорт через существующий сериализованный код билда;
- **Compare Builds** для сравнения характеристик двух сохранённых билдов рядом, включая нейтральную разницу `Билд B − Билд A`;
- доступные с клавиатуры подсказки по характеристикам: что показывает значение и из какого точного узла Legacy 2.00 оно читается;
- переход сразу к калькулятору с клавиатуры и модальные окна, которые удерживают фокус внутри и возвращают его к кнопке открытия по Escape;
- окно **Обновления** на сайте: отдельные версии Legacy и интерфейса, краткие изменения и полный changelog;
- компактная закреплённая сводка персонажа и сворачиваемые подробные блоки на телефонах;
- устанавливаемый PWA-интерфейс с надёжным офлайн-запуском Modern и Legacy Mode;
- ненавязчивое уведомление об обновлении, которое позволяет сначала закончить или сохранить работу;
- единая панель языка EN/RU/JP/TW: RU с английским запасным текстом, либо исходные JP/TW игровые названия с английской современной оболочкой;
- просмотр характеристик вещей и Souls в Modern-поиске и кнопка **Поделиться билдом**: ссылка восстанавливает персонажа в другом браузере;
- в этой версии автосохранения и именованные билды хранятся только в текущем браузере.

Compare Builds не подменяет формулы игры собственной математикой: оба билда рассчитываются через сохранённый старый расчётный путь, после чего активный персонаж восстанавливается. В подсказках намеренно нет выдуманной детализации формул по статам, экипировке или баффам, если такие составляющие не были отдельно подтверждены.

В [Excel-таблице](localization/translations.xlsx) столбец H (жёлтый) предназначен для русского текста, I (зелёный) — для изменения английского. Исходные столбцы не меняйте. Все действия описаны в [инструкции для начинающих](docs/LOCALIZATION_FOR_BEGINNERS.ru.md). Заполненные переводы отображаются в современном калькуляторе, списках, поиске и описаниях навыков. Пустые игровые поля сохраняют выбранный исходный язык; Legacy Mode не меняется.

Modern 3.04 опубликован. Берите свежую таблицу из основной ветки; после её
загрузки сайт автоматически проверяет и публикует переводы. Шесть разделов
редактора Worker/D1, реальные возможности и исправление прямого входа описаны
в [инструкции администратора](docs/ADMIN_OPERATIONS.ru.md). Облачного хранения
билдов игроков здесь нет.
Новые активные и пассивные навыки можно создавать по исходным шаблонам изучения.
Их описание и условия бонуса открываются во всплывающей панели SKILL.
Порядок создания, проверки и публикации описан в
[пошаговой инструкции по новым навыкам](docs/ADMIN_NEW_SKILLS.ru.md).
Если непонятно, где менять характеристики, начните с
[инструкции по редактированию](docs/ADMIN_EDITING_FOR_BEGINNERS.ru.md):
действующие значения, проверка изменений, черновик и публикация разобраны по шагам.
В Modern 3.04 секции калькулятора оформлены в Hybrid C; JOB/SKILL снова
всплывают и закрываются повторным нажатием. Ошибки ввода называют конкретное
поле и его предел; подписи и поля BUFF выровнены. Уровень и шесть характеристик
вводятся прямо в поля; выбор вещей на телефоне сохраняется при изменении высоты экрана.
Сравнение скрывает одинаковые строки, редактор показывает текущие параметры
и серверную проверку изменений отдельно. Вход проверен с прежним паролем.
Собственные условия изучения и новые классы остаются дальнейшими этапами.
