## 🎮 Что это

**Pandora Saga Simulator Remaked** возвращает к жизни старый браузерный калькулятор персонажа Pandora Saga и постепенно обновляет его интерфейс, не заменяя исходную расчётную логику.

Проект предназначен для игроков, которые хотят экспериментировать с классами, характеристиками, навыками, экипировкой и другими настройками персонажа без зависимости от давно недоступной страницы FC2.

Modern использует постоянно актуализируемый каталог игровых данных поверх сохранённого расчётного пути Legacy 2.00. Сохранённые Modern-билды хранят выбор игрока, но автоматически переводятся на текущие данные; Legacy Mode остаётся нетронутой исторической версией.

## ✨ Современный режим

Главная страница открывается в **Modern Mode**:

- обновлённый светлый гибридный интерфейс в духе оригинального зелёного симулятора;
- английский язык по умолчанию;
- сохранены японские и традиционные китайские данные старой версии;
- адаптивная оболочка для обычных мониторов, широких экранов, планшетов и телефонов;
- **поиск и выбор экипировки прямо в каждом слоте** оружия, брони и аксессуаров: совместимость, фильтры по названию/уровню, характеристики по наведению на компьютере и значок информации на телефоне; просмотр не меняет экипировку;
- **поиск и выбор Soul прямо в каждой доступной ячейке**, только среди совместимых вариантов;
- автоматическое локальное сохранение билда и восстановление после обновления страницы;
- **Build Manager** для именованных локальных билдов: сохранить, загрузить, переименовать, скопировать и удалить;
- импорт и экспорт через существующий сериализованный код билда;
- **Compare Builds** для сравнения характеристик двух сохранённых билдов рядом, включая нейтральную разницу `Билд B − Билд A`;
- доступные с клавиатуры подсказки по характеристикам: что показывает значение и из какого точного узла Legacy 2.00 оно читается;
- переход сразу к калькулятору с клавиатуры и модальные окна, которые удерживают фокус внутри и возвращают его к кнопке открытия по Escape;
- окно **Обновления** на сайте: отдельные версии Legacy и интерфейса, краткие изменения и полный changelog;
- компактная закреплённая сводка персонажа и сворачиваемые подробные блоки на телефонах;
- только онлайн-режим без установки и офлайн-кэша, чтобы калькулятор работал на одной актуальной веб-версии;
- автоматическая проверка свежего релиза: сайт ждёт короткую паузу в действиях, сохраняет билд и загружает новые Modern-файлы без обычной необходимости в Ctrl+F5;
- единая панель языка EN/RU/JP/TW: RU с английским запасным текстом, либо исходные JP/TW игровые названия с английской современной оболочкой;
- просмотр характеристик вещей и Souls в Modern-поиске и кнопка **Поделиться билдом**: ссылка восстанавливает персонажа в другом браузере;
- в этой версии автосохранения и именованные билды хранятся только в текущем браузере.

Compare Builds не подменяет формулы игры собственной математикой: оба билда рассчитываются через сохранённый старый расчётный путь, после чего активный персонаж восстанавливается. В подсказках намеренно нет выдуманной детализации формул по статам, экипировке или баффам, если такие составляющие не были отдельно подтверждены.

| Русский | Современный интерфейс доступен; игровые названия ждут сверки с русским клиентом Pandora Saga |

Переводы Modern теперь редактируются в защищённой админке на **четырёх языках**: RU / EN / JP / TW. Разделы включают интерфейс, классы, расы, навыки, снаряжение, души, характеристики и описания. Базовые утверждённые записи сохранены при переносе, а новые правки публикуются без редактирования Excel. Подробнее — в [инструкции по переводам](docs/LOCALIZATION_FOR_BEGINNERS.ru.md). Legacy Mode остаётся неизменным.

В Modern **3.47** улучшен единый редактор переводов: отображается отсутствие перевода, доступны фильтры непереведённых строк и правок админки. Ранее использовавшиеся русские подписи доступны для редактирования, а переводы разных полей описаний душ не смешиваются. Игровые формулы и сохранённые билды не изменены.

Modern проверяет маленький манифест версии без кэша при запуске, возврате во вкладку, восстановлении сети и периодически, пока вкладка видима. Если вышел новый релиз, сайт ждёт короткую паузу в действиях, завершает ввод в активном поле, принудительно сохраняет билд и перезагружает версионированные файлы. Сайт намеренно работает только онлайн; вручную чистить кэш или cookie обычно не требуется.

Кнопка **Обновления / Что нового** показывает пункты из верхнего релиза [CHANGELOG.md](CHANGELOG.md), а номер Remaked UI берётся из того же источника во время сборки. Поэтому номер версии, краткие заметки на сайте и полный changelog синхронизируются автоматически.

Публичная документация описывает возможности для игроков, устройство проекта, историю и планы. Приватные инструкции по администрированию каталога и учётным данным в публичную документацию не входят.

## 🚧 Что планируется

Основные направления:

- дальнейшая сверка текущих предметов, Souls, классов и навыков по подтверждённым данным;
- проверенные русские игровые названия и описания;
- расширение поддерживаемых условий и эффектов без выдумывания отсутствующих Legacy-формул;
- дальнейшая визуальная, touch, клавиатурная и cross-browser полировка;
- сохранение старых выборов и ссылок с автоматическим пересчётом по текущим данным каталога.

История опубликованных изменений — в [CHANGELOG.md](CHANGELOG.md).
