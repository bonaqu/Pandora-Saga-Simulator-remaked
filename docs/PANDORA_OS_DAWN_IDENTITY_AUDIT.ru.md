# Dawn: предварительная сверка идентичностей и ограничений

Срез публичных данных 28 октября 2026, каталог Modern revision 92. Это **сопоставления для проверки**, а не разрешение автоматически объединять записи или публиковать импорт. Источник не отдаёт отдельные поля расы и пола в `items.json`: RU/EN названия и описания называют предполагаемого носителя, а ниже сопоставлены с историческими флагами Legacy. На сервере могли измениться правила; буквальное совпадение названия и эффектов само по себе не доказывает идентичность.

Для каждой пары совпадают категория, уровень 20, количество сокетов и все автоматически сопоставляемые базовые численные эффекты. Значения, не поддерживаемые преобразователем, при сравнении не считаются нулевыми. Отдельных опубликованных override для этих 27 ID в ревизии 92 нет; записи доступны из базового Legacy-каталога. Проверка не видит приватные черновики D1.

Столбец `пол / раса` — **исторические** первые восемь флагов `[М, Ж, человек, эльф, цверг, мирина, энкиду, кролль]`, а не машиночитаемый атрибут свежего API. `М+Ж` значит оба пола по архивной записи.

Три пары серверных ID ведут к одному историческому ID: 12522/12532, 14502/14512 и 15502/15512. Нельзя автоматически записывать их в one-to-one карту или создавать новые дубли. Исторические перчатки/сапоги также разрешают оба пола, хотя название серверной записи может указывать один. Нужно отдельно решить представление двух игровых ID и совместимость сохранённых билдов на основе проверенного поведения и данных; пока эти соответствия остаются кандидатами.

Для 11542 преобразователь не моделирует `EP_RACE_RANGE` и `EP_RACE_CARRY`. Для 13502/13512 `EP_IMMUNE_DISEASE` и для 13572 `EP_IMMUNE_RAVING` дополнительно сопоставлены с имеющимися показателями сопротивления болезни (161) и безумию (157): названия и числа совпадают в RU/EN описаниях, а локальный тест проверяет изменение соответствующих результатов защиты при надевании и снятии. Это ещё не подтверждение вероятностей в бою. Текущий редактор новых предметов сохраняет расовые флаги, но для новых записей не задаёт первые два половых флага; в проверке допустимости Modern используются раса и класс. Нельзя утверждать, что действующее ограничение пола уже моделируется.

Воспроизведение GET-only без изменения D1:

```powershell
node scripts/audit_pandora_os_dawn_candidates.mjs D:/CODEX/Tasks/pandora-admin-runtime/pandora-os-identity-audit-20261028.json
```

Скрипт отказывается работать при изменении SHA снимков предметов, английской локализации или публичного каталога с момента указанного identity-аудита. Он выводит полный JSON с исходными описаниями, flags, значениями и нераспознанными эффектами. Для свежего среза сначала повторяют общий identity-аудит. Данные публичного веб-калькулятора не подтверждают результат в игровом клиенте.
