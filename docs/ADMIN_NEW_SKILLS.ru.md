# Как создать новый навык в админке

Статус: инструкция для кандидата Modern 3.02, draft PR28. На рабочем сайте
пока опубликован Modern 3.01. Пункты ниже станут доступны после проверенного
выпуска; это не сообщение о состоявшемся обновлении.

## Что означает «шаблон»

Калькулятор умеет проверять исходные условия изучения навыков: класс, уровень
и распределённые очки веток. Новый навык пока получает условие изучения одного
из существующих навыков. Он не заменяет этот исходный навык.

Например, если выбрать шаблон Recovery Effects increased, новый навык появится
для того же персонажа, который изучил исходный. Но увеличение эффекта зелий
автоматически не копируется. Для новой пассивки работают только числа,
которые вы сами указали. Для активного навыка пока доступны описание, MP и
время. Симуляции его боевого урона здесь нет.

## Создать и проверить

1. Откройте настоящую админку: <https://pandora-saga-simulator-remaked-admin-api.bonaqu.workers.dev/admin>.
2. Если вкладка открыта давно, нажмите `F5`. Введите `admin`. Пароль скопируйте
   только после `Пароль:` из личного файла; не загружайте этот файл на GitHub.
3. Выберите раздел **Активные навыки** либо **Пассивные навыки**. Найдите
   исходный навык с подходящим условием изучения и откройте его карточку.
4. Нажмите **Создать новый навык по этому шаблону**. Это ещё ничего не
   публикует. Исходная карточка останется неизменной.
5. Укажите новое **English**-название. Оно обязательно. В **Русский** впишите
   русское название, если уже знаете его. JP/TW можно оставить пустыми:
   тогда для нового навыка будет показано английское название.
6. Заполните описание. Это обычный текст, не формула и не HTML.
7. Для активного навыка укажите MP и секунды применения, перезарядки и
   длительности. MP — целое число; время допускает до трёх знаков после запятой.
8. Для пассивки нажмите **Добавить характеристику**, выберите нужный показатель,
   единицу и число. Допускается до двух знаков после запятой. Текст
   «Сила +5» в описании сам по себе силу не добавляет — нужен числовой бонус.
9. Проверьте условия бонуса. Несколько типов оружия означают «любой из них».
   Отмеченные щит и верховая езда требуются дополнительно. Пустой список оружия
   разрешает любое оружие; «Без оружия» означает именно пустую правую руку.
10. Нажмите **Сохранить черновик**. Черновик виден только вам. Проверьте
    название, цифры и шаблон. Для изменения типа или условия изучения создайте
    другой навык: уже выделенный ID и шаблон не переопределяются.
11. Только когда всё проверили, нажмите **Опубликовать**. Появится новый номер
    каталога. Не нажимайте публикацию для случайных тестовых характеристик.
12. Откройте обычный сайт. У нового посетителя загрузится опубликованный
    каталог. Для старого билда откройте **Билды → Обновить текущий билд**:
    сохранённые билды не меняют расчёт незаметно.
13. Выберите нужный класс, уровень и распределите очки. Откройте вкладку
    **SKILL**. Под калькулятором появится **Дополнительные навыки каталога**.
    Нажмите строку навыка: увидите условие изучения, описание и параметры.
14. У пассивки проверьте **Изучен** и **Бонус пассивки действует**. Если бонус
    не действует, проверьте указанное оружие, надетый щит и включённую езду.
    Затем проверьте результат в характеристиках персонажа.
15. Поделитесь билдом через **Билды**. Ссылка сохраняет номер каталога;
    получатель не должен получить другие цифры из более нового обновления.

## Если ошиблись

Не удаляйте базу и не меняйте пароль. Исправьте карточку, сохраните черновик
и опубликуйте новую версию. Для отмены публикации используйте восстановление
предыдущей версии в админке: старые номера остаются доступны старым билдам.
Если другая вкладка изменила каталог, обновите список и сверяйте данные;
защита от устаревшей вкладки не должна молча перезаписать чужую правку.

Предел этого этапа — 256 новых навыков всего. Новые классы, собственные
правила изучения и новая боевая механика остаются дальнейшими этапами.

Названия/описания созданного в админке навыка меняйте в его карточке.
`translations.xlsx` переводит исходный каталог и подписи интерфейса; он не
заменяет числовые характеристики, черновики или новые записи D1. Инструкция
по Excel: [Как менять русский и английский текст](LOCALIZATION_FOR_BEGINNERS.ru.md).
