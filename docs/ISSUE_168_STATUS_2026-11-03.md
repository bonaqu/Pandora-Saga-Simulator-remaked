## Частично / до проверки в действующей игре

1. **Полный паритет 43 показателей.** Доказаны отдельные игровые сценарии, но не все комбинации рас, классов, Souls, заточки, пассивок, баффов, езды и округления. Сравнения Modern↔Legacy не подтверждают актуальность игрового клиента.
2. **Эффективная дальность атаки.** Проверена базовая дальность, но не независимое влияние всех навыков, Riding и `EquipOpt[40/41]`. До появления эталонов нельзя выдавать вычисленную эффективную дальность за игровую.
3. **JP/TW — граница поддержки игровых текстов.** Существующие названия и описания вещей архивного Legacy JP/TW сохраняются без изменений. Текущий игровой сервер не предоставляет официального нового JP/TW перевода предметов: для новых игровых ID используется английский fallback, **новые JP/TW игровые переводы не создаются**. Проверки полноты старого набора остаются допустимы только в read-only режиме. Новые локализуемые элементы *интерфейса* — отдельная область и могут переводиться на JP/TW.
4. **320–1920 px, RU/EN/JP/TW.** Отдельные адаптивные сценарии есть в CI, но исчерпывающая матрица всех админских и игровых экранов не доказана.
5. **Dawn и редактирование.** Исторические 35 предметов редактируемы через обычные ID. Пять Modern-only записей до этого аудита были клиентской проекцией, не отдельными источниками админки. Новая работа над их серверной редактируемостью должна завершить Feature CI и production deploy; сами изменения в D1 по-прежнему выполняются только после обычной авторизованной публикации.

## Порядок дальнейшей работы без риска для данных

- Оригинальный технический `range` у оружия считается **подтверждённой базовой дальностью**. Не смешивать её с непроверенным суммарным влиянием Riding/умений/экипировки; см. [разбор расовых комплектов и дальности](RACIAL_DAWN_VERIFIED_NAMES_2026-11-03.md).
- Для нового независимого эталона доступен предложенный [тест №4](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/issues/168#issuecomment-6155712464): тот же Воин ELF lvl1 с «Очками разума» ID 11122 (+1 СД) и «Кольцом с кристаллом» ID 19004. До игрового снимка расхождение не считается доказанной ошибкой формулы.
- Для локализации использовать только уже созданный защищённый read-only аудит D1; не имитировать авторизованную сессию и не подменять неподтверждённые варианты исходников опубликованными.
- Разработческими тестами фиксировать отсутствие `NaN`/`undefined`, не превращать наездника с DEF `---` в DEF 0.
- Legacy 2.00 и уже опубликованные вручную D1-переводы не изменять; текстовые правки не должны менять impact revision сохранённого билда.

**Статус issue: OPEN**, потому что полного игрового паритета и независимого реального JP/TW coverage здесь не доказано.
