## Что осталось для достоверного аудита production

1. Считать эффективные тексты **через авторизованный API** D1, отдельно для актуального каталога и `localization_overrides`, не раскрывая сессии и токены.
2. Сопоставить по стабильным ID текст интерфейса, оригинал EN, утверждённые fallback и уже опубликованные значения. Приоритет D1 выше локального JSON.
3. Получить поддающийся повторению отчёт именно о **непереведённых эффективных** RU/EN/JP/TW строках; сохранять историю, версии, tombstone и пользовательские правки.
4. Только после этого предложить переводы с подтверждёнными именами и характеристиками; никакого автоматического перезаписывания опубликованных D1 записей.

См. [Issue #168](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/issues/168) и [аудит игровых расчётов](CALCULATION_PARITY_AUDIT_2026-10-11.md).


## Дополнение: список недостающих идентичностей JP/TW — 12.10.2026

Офлайн-аудит теперь предоставляет проверяемый список **стабильных ID**, для которых в историческом игровом справочнике нет исходной строки JP или TW:

- `missingSourceIds.jp`: **48** ID из 2678.
- `missingSourceIds.tw`: **60** ID из 2678.
- `byCategory[категория].missingSourceIds.jp/tw`: те же пробелы по категориям. Подытоги строго сверяются с общими числами; ID отсортированы для повторяемого сравнения.

Текущий реестр UI содержит **630** английских ключей; из локально одобренных fallback RU имеет 563/630, JP и TW по 629/630 (их намеренно пустой sentinel `test.englishOnly`). Эти показатели относятся **только к репозиторию**, не к опубликованной D1.

Команда `node scripts/audit_localization_baselines.mjs --json --check` работает только на чтение. Отсутствие исходного JP/TW текста **не равно** отсутствию опубликованного перевода на сайте: D1 override и каталог могут содержать актуальные версии. Отчёт не запрашивает и не публикует D1, не трогает ручные переводы, не создаёт черновиков, не делает автоматический машинный перевод и не предлагает подставлять значения без подтверждённого первоисточника. Для фактического покрытия production используйте авторизованный отчёт центра переводов Modern 4.03.
