# Снимок покрытия исходных переводов — 11.10.2026

**Область:** только версии файлов, зафиксированные в GitHub. Это **не проверка фактических опубликованных переводов Cloudflare D1 и каталога Modern**. Не использовать счётчик отсутствующих строк в исходниках для автоматического сброса, импорта или публикации перевода.

Источник: `localization/game-terms.ru.json`, `localization/approved-translations.v1.json`, `localization/ui.en.json`. Проверяемый скрипт: `node scripts/audit_localization_baselines.mjs --json --check` (только чтение).

## Что осталось для достоверного аудита production

1. Считать эффективные тексты **через авторизованный API** D1, отдельно для актуального каталога и `localization_overrides`, не раскрывая сессии и токены.
2. Сопоставить по стабильным ID текст интерфейса, оригинал EN, утверждённые fallback и уже опубликованные значения. Приоритет D1 выше локального JSON.
3. Получить поддающийся повторению отчёт именно о **непереведённых эффективных** RU/EN/JP/TW строках; сохранять историю, версии, tombstone и пользовательские правки.
4. Только после этого предложить переводы с подтверждёнными именами и характеристиками; никакого автоматического перезаписывания опубликованных D1 записей.

См. [Issue #168](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/issues/168) и [аудит игровых расчётов](CALCULATION_PARITY_AUDIT_2026-10-11.md).

Текущий реестр UI содержит **630** английских ключей; из локально одобренных fallback RU имеет 563/630, JP и TW по 629/630 (их намеренно пустой sentinel `test.englishOnly`). Эти показатели относятся **только к репозиторию**, не к опубликованной D1.

Команда `node scripts/audit_localization_baselines.mjs --json --check` работает только на чтение. Отсутствие исходного JP/TW текста **не равно** отсутствию опубликованного перевода на сайте: D1 override и каталог могут содержать актуальные версии. Отчёт не запрашивает и не публикует D1, не трогает ручные переводы, не создаёт черновиков, не делает автоматический машинный перевод и не предлагает подставлять значения без подтверждённого первоисточника. Для фактического покрытия production используйте авторизованный отчёт центра переводов Modern 4.03.


## Проверка связанного D1-интерфейса — Modern 4.14, 12.10.2026

Реестр UI насчитывает **726** английских ключей. После ручного утверждения 48 дополнительных RU UI-строк для локального fallback имеются **707 RU, 725 JP и 725 TW** переводов; единственный незаполненный JP/TW ключ — намеренный тестовый `test.englishOnly`. Исторические цифры выше оставлены для сопоставления снимков, а не как актуальные результаты. Эти значения **не показывают фактическую опубликованную D1-покрытость**.

В админке дополнительно локализованы **14** строк: контекстная подсказка восстановления базового перевода и облачного черновика; доступные имена четырёхъязычного редактора; причины пропусков и конфликты массовой замены; сообщение о неопределённом исходе D1-транзакции с обязательной проверкой `operationId`. При смене языка переводы динамических ошибок и подсказок обновляются без пересоздания полей ввода, удаления черновиков или повторных публикаций.

Проверка `tests/test_admin_workflow_live_translations.py` сверяет все четыре локали, плейсхолдеры, безопасность текста и защитные границы API. `tests/ui/admin-bulk-error-localization.spec.mjs` воспроизводит слишком большой набор строк, переключает языки без нового GET и убеждается, что POST не вызывается. Подтверждение транзакции по квитанции остаётся обязательным: сетевой сбой **не** доказывает отсутствие записи в D1.

## Актуализация RU-подсказок для игроков — Modern 4.14

Из 67 недостающих локальных RU UI fallback заполнены **48** пользовательских строк (с сохранением ранее утверждённых формулировок через `curated-runtime-defaults.ru.v1.json`): 26 описаний расчётных характеристик, подписи мастерства/потенциала, пользовательское сообщение «Что нового», статусы актуализации билдов и причины несовместимости, изменение количества ячеек душ и предупреждение об ограничении расчёта. Известные формулировки точности намеренно не обещают соответствие актуальной игре: это объяснение **показателей, выводимых симулятором**, а не независимая валидация формул.

Оставшиеся **19** непереведённых ключей имеют отдельные причины: исходные аббревиатуры параметров, намеренно англоязычная стилистика скрытого входа в админку, диагностический Legacy-индикатор, исторический идентификатор PRV и тестовый sentinel. Их не следует автоматически переводить или смешивать с реальными игровыми терминами. `tests/test_ru_ui_fallback_completion.py` автоматически проверяет все новые RU-подписи, параметры `{...}`, отсутствие HTML и отсутствие неожиданных новых пробелов. Никакие публикации D1 и оригинальные переводы других языков не изменены.

Дополнительная инвентаризация обнаружила конфликт первоначально предложенных fallback для `skills.adeptness` и `skills.potential` с уже утверждёнными русскими формулировками. Перекрывать их было бы неправильно: сохранены **«Изучено (ОЧ)»** и **«Потенциал.»**. Для `skills.help` намеренно сохранён **отдельный неизменяемый approved snapshot**, который отличается от curated-представления; смешивать эти два слоя нельзя. Регрессия сравнивает четыре ранее утверждённых общих UI-ключа с curated-значениями, а `skills.help` отдельно проверяет как независимый источник. Действующие D1-публикации по-прежнему имеют приоритет.


## Безопасная выгрузка эффективных отсутствующих ID через авторизованную D1 — Modern 4.15

В **едином центре переводов админки** после ручной кнопки «Проверить опубликованные переводы» появилась отдельная кнопка «Скачать непереведённые ID (JSON)». Администратор запускает выгрузку явно; это **не фоновое сканирование**, не автоперевод и не публикация.

Алгоритм повторно читает только страницы `GET /api/admin/localization?scope=...&locale=...&group=all&status=missing&page=...` для восьми сочетаний `scope × locale` (game/ui × RU/EN/JP/TW), сравнивает ответ каждой страницы с итогами первого просмотра, проверяет `page/pageSize`, тип идентичности, исходный `fallback`, отсутствие дублей и точное ожидаемое количество ID. Защита: не более **6000 отсутствующих ID для одного сочетания**; при изменении общего счётчика D1 или неполном ответе экспорт останавливается, **файла частичных результатов нет**. Кнопка блокируется на время работы; более новый запуск общего аудита отменяет старую выгрузку.

Скачиваемый JSON содержит `schemaVersion`, `createdAt`, `atomic:false`, `readOnly:true`, `includesTranslationText:false`, агрегированное покрытие и отсортированные стабильные идентификаторы с категорией (`id`, `kind`, `managedBy`). **В нём нет** логинов, токенов, секретов, исходных строк, эффективных текстов, черновиков или квитанций публикации.

Данные отражают **настоящую авторизованную D1 и опубликованный каталог во время чтения**, в отличие от исторического реестра; но несколько HTTP-запросов не образуют транзакционно атомарный снимок. Незаметное изменение набора ID при неизменном общем количестве не исключается; для строгой синхронизации нужен серверный снапшот или фиксированная ревизия. Отчёт предназначен для проверки и утверждения переводов, а **не** для автоматического перезаписывания D1.

Все четыре языковые подписи добавлены в D1-first `adminShell`-реестр. Проверки `tests/ui/admin-effective-missing-export.spec.mjs` имитируют публично-пустой и непустой каталог, отсутствие POST/секретов и отказ при изменении счётчика.
