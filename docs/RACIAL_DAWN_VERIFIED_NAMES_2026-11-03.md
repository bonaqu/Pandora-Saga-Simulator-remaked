# Расовые комплекты / Зари — проверка оригинальных названий (2026‑11‑03)

## Источники и критерий идентичности

- [Pandora Saga OS — items.json](https://pandorasaga-os.com/gamedata/items.json): реальные числовые ID, русское поле `name`, тип/слот, базовые расчётные свойства и уровень.
- [Pandora Saga OS — strings.en.json](https://pandorasaga-os.com/gamedata/strings.en.json): английские названия по тем же ID.
- [Сохранённый игровой снимок](../admin-api/data/pandora-os-live-items-20261007.json) и неизменяемый [архивный item.js](../js/item.js) дают сопоставления с предыдущим индексом, формулой и JP/TW-оригиналами.
- Машинного перевода оригинальных игровых предметов JP/TW **нет**. У ранее присутствовавших в архиве позиций японские/традиционные китайские названия остаются прежними. У новых для Legacy предметов вместо отсутствующего официального перевода используется **английское** название. Дальнейшая локализация JP/TW относится к интерфейсу сайта, а не к созданию новых переводов игровых вещей.

## Управление и стабильность

- [Единый проверенный реестр](../data/verified-racial-gear.v1.json) содержит все 72 ID, привязку к исходному индексу, русский/английский текст и пол/расу.
- Исторические 52 позиции редактируются по штатным ID `equipment.<category>.<index>`. Десять вновь разделённых женских ID — отдельные базовые записи защищённого каталога с обычными черновиками и публикацией. Уже опубликованные в D1 UUID-варианты (10 вещей Зари) имеют собственные редактируемые карточки, не заменяются автоматическим импортом.
- При изменении названия/описания вручную посредством админки авторская публикация остаётся приоритетнее штатного RU/EN fallback. Нет автозаписи в производство или переписывания исторического Legacy.
- Идентификация не строится на равенстве статов: для 72 записей используются **точные игровые ID** с привязкой к конкретной расе/полу. Тесты запрещают дубли одного ID или индекса.

## Базовая дальность оружия

Число `range`, указанное в технических данных конкретного оружия текущего игрового сервера, — **подтверждённая базовая дальность** этого оружия. Её не следует переобъявлять «непроверенной». Независимо от базового параметра могут существовать эффекты навыков/езды/экипировки, меняющие эффективную дистанцию: их порядок/стек проверяется по отдельным игровым эталонам. Не переименовывать игровые единицы в метры без отдельного источника.

## Несовпадение официальных языковых файлов

Для OS ID `12531` русское поле `name` — «Жилет для эльфа (Ж)», а английское `strings.en.json` — «Skirt (Female Elf)». Сохранены буквально проверенные языковые значения соответствующих источников; они не исправляются наугад. Это требует отдельного исправления исходной игровой локализации, но не мешает идентификации по числовому ID.
