# Как редактировать данные симулятора

Административная панель доступна только после авторизации в защищённом Cloudflare Worker. Публикация влияет на Modern-версию симулятора; Legacy остаётся неизменным.

## Перевод результатов расчёта

Откройте раздел **«Расчётные характеристики · RU / Excel / админка»**. Там доступны 43 характеристики.

- **Excel (основной)** — утверждённое значение из `localization/translations.xlsx`. Основной набор переводов опубликован вместе с сайтом.
- **Перевод RU** — текущее отображаемое значение. Если администратор публиковал собственный текст, он имеет приоритет над Excel.
- **Сохранить** — немедленно публикует только конкретную русскую подпись. Это не изменяет формулы, характеристики предметов, версии билдов или остальные языки.
- **Вернуть Excel** — отменяет опубликованное ручное переименование и снова использует базовую строку.
- **Статус** показывает, берётся ли перевод из Excel или опубликован через админку, а также номер версии.

Если название успели изменить в другой вкладке, сохранение завершится конфликтом. Перезагрузите значения и решите, какую формулировку оставить. Никаких массовых перезаписей существующих переводов не выполняется.

**Важно:** редактирование через админку не делает обратный коммит в GitHub `translations.xlsx`. Для постоянного изменения основной книги откройте `localization/translations.xlsx`, измените только столбец H по стабильному ID и опубликуйте PR. Сохранённые админские правки при этом продолжают иметь приоритет. Все 43 базовых названия сопоставлены по ID с `localization/calculator-results.ru.json`; CI отклонит рассинхронизацию.

## Снаряжение, души, умения, классы

Эти объекты редактируются в основном каталоге ниже. Проверьте черновик перед публикацией, особенно расчётные бонусы. Если меняете только название или описание, характеристики персонажа не меняются.

Для вопросов по базовым переводам: [Translation workbook](../localization/README.md).
