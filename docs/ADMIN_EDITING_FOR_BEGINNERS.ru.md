# Как менять вещи, души и навыки в админке

На сайте опубликован Modern 3.07; настройка изучения из готовящейся 3.08
ещё ожидает публикации. Музей `/legacy/` не меняется.

## 1. Войти

1. Откройте [админку](https://pandora-saga-simulator-remaked-admin-api.bonaqu.workers.dev/admin).
2. Логин — `admin`. Пароль скопируйте из строки `Пароль:` в вашем локальном
   файле `D:\CODEX\Private\PandoraSagaSimulator\admin-login.txt`.
   Копируйте только сам пароль, без слова `Пароль:` и пробелов вокруг.
3. Нажмите `AUTHENTICATE`. После входа появится каталог.

Пароль не отправляйте в переписку, не загружайте на GitHub и не вписывайте
в Excel. Если вход временно ограничен после нескольких попыток, подождите
минуту. Страница API `/api/auth/login` — не страница входа: используйте `/admin`.

## 2. Найти нужную запись

1. В выпадающем поле **Каталог** выберите нужный раздел.
2. В поиске введите часть английского или русского названия. Русское имя найдётся,
   если его уже добавили в админке. Можно искать по техническому ID.
3. Нажмите название в списке. На ПК список слева, на телефоне — над редактором.

| Что хотите менять | Раздел |
| --- | --- |
| Оружие, броню, украшение | Экипировка / оружие |
| Вставляемую душу | Souls / души |
| Stone Skin, Magic Resistance, другой расовый бонус | Расовые пассивки; рядом с названием указана раса |
| Нажимаемое умение, его MP и время | Активные навыки |
| Пассивное умение, изучаемое персонажем | Пассивные навыки |
| Название класса и его параметры роста LP/MP | Классы персонажей |

Смена раздела закрывает предыдущую запись. Если вы что-то набрали и не
сохранили, редактор предупредит; отмена оставит ваши поля на месте.

## 3. Посмотреть, что действует сейчас

Блок **Сейчас на сайте** показывает действующую запись — не ваш приватный
черновик. Там видны описание, числовые эффекты, атака, слоты или параметры навыка.
Если изменений ещё не публиковали, это исходные данные Legacy.

Блок **После публикации** сначала пустой. Он заполнится после кнопки
**Проверить изменения**. Это данные конкретной записи, а не весь расчёт билда:
итог персонажа дополнительно зависит от класса, уровня, экипировки и баффов.

Под этими блоками находятся **Редактируемые поля**. Менять нужно их.
Не пытайтесь редактировать текст внутри блока «Сейчас на сайте».

## 4. Изменить название или описание

1. Найдите поле `English` или `Русский` в группе названия.
2. Замените текст. Английское название обязательно; русский перевод можно
   оставить пустым — тогда игрок увидит доступное исходное название.
3. Для японского или китайского нажмите **Японский и китайский переводы**.
   Закрытые поля не удаляются при сохранении.
4. Описание меняется в отдельной группе. **Описание не является формулой.**
   Фраза «СИЛ +5» в описании сама по себе не даст +5 силы в калькуляторе.

Особые эффекты и место получения разворачиваются отдельно: это тоже текст.
Для массового перевода удобнее [инструкция по Excel](LOCALIZATION_FOR_BEGINNERS.ru.md).
В Excel русский вводится в H, изменение английского — в I; исходные E–G не трогайте.
Для одной записи удобнее админка: публикация не требует коммита и сборки Pages.
Опубликованное название из админки имеет приоритет над таблицей для этой записи.

## 5. Изменить реальные характеристики вещи или души

Пример: добавить или заменить `СИЛ +5` у существующей вещи.

1. В **Расчётные характеристики** оставьте режим
   **Изменить перечисленные характеристики**.
2. Нажмите **Добавить характеристику**.
3. Выберите **Сила (СИЛ / STR)**, впишите `5`, оставьте единицу **Число**.
4. Нажмите **Проверить изменения** и проверьте результат справа.
   Остальные исходные характеристики сохранятся; сила будет заменена на +5.

Не выбирайте «Заменить исходную числовую строку» для обычной небольшой правки:
этот режим удаляет другие исходные числовые бонусы записи. Для новых вещей
нужно задать все их числа явно. Неизвестные условные эффекты нельзя придумать
в поле описания: редактор не выполняет произвольный код.

Оружию отдельно задаётся **Базовая атака**. Пустое поле у исходного оружия
означает «оставить исходную атаку», её видно в блоке слева. Это не ноль.
Число слотов душ — от 0 до 3. Также проверьте разрешённые расы, классы или
места вставки души. Душу нельзя вставить, если ни один слот не разрешён.

## 6. Расовая или изучаемая пассивка: важное различие

**Расовая пассивка** действует только если персонаж её выбрал.

- **Сохранить исходную механику** — меняете только текст.
- **Добавить к исходной механике** — добавляете указанные числа к исходным.
- **Заменить исходную механику** — исходный расчёт отключается, остаются только
  указанные числа. Пустая замена означает отсутствие расчётного эффекта.

`5` в единице «Процентные пункты» — это +5 пунктов шанса крита, например
с 10% до 15%, а не 5% от десяти. В подготовленных текущих записях 3.07
используется **замена**, а не добавка: Stone Skin — только получаемый физический
урон `−10%`, Magic Resistance — только получаемый магический урон `−10` п.п.
Не добавляйте к ним строку шанса крита: она не относится к этим способностям.
Старые закреплённые каталоги 1/2 используют отдельную историческую коррекцию
`−2` к ошибочным +2 крита. Не переносите её в новую полную замену.

Для «Бойцовского духа» и «Духа цверга» нужны **две строки атаки**: `10` в
единице «Число» и `12` в «% от базы». Это не +22%. Под ними выберите разрешённые
категории оружия: пустой набор означает любое оружие, не отсутствие бонуса.
При неподходящем оружии замена всё равно отключает старую механику, но новые
условные числа не применяются. Безоружное состояние — отдельная галочка.

«Получаемый шанс крита» и «Получаемый критический урон» — защитные параметры:
минус уменьшает их. Они не повышают собственный шанс критического удара.
Поле **Ограничения расчёта** объясняет справочные эффекты вроде дальности +500
или шанса пережить последний удар: текст этого поля сам не даёт числовой бонус.

Блок слева объясняет встроенную механику. Некоторые способности вообще не
моделируются в старом калькуляторе — это отмечено явно. Их нельзя считать
проверенными игровыми эффектами только потому, что существует название.

**Изучаемая пассивка** работает при изучении и с указанным снаряжением.
У исходной пассивки встроенный эффект сохраняется; числа редактора — добавка,
а не полный список её эффектов. Если дополнительных строк нет, это не значит,
что исходная пассивка ничего не даёт. Для нового навыка по шаблону исходная
механика не копируется: бонусы нужно указать явно.

## 7. Активные навыки и классы

У активных навыков редактируются MP, время применения, перезарядка,
длительность и текст. Это не создаёт формулу боевого урона: движок пока
не моделирует бой. По умолчанию сохраняются условия исходного шаблона.
В подготовленной 3.08 блок **Условия изучения навыка** позволяет отдельно
выбрать классы, минимум уровня и очки веток. Пустой выбор классов — любой;
несколько веток требуются одновременно. Подробный пример:
[Настройка изучения](ADMIN_NEW_SKILLS.ru.md#свои-условия-изучения-подготовлено-для-308).

У класса первые два числа — базовые LP/MP. Остальные — **делители** роста,
не прямое «+HP за уровень»: меньше делитель — больше рост. Делитель нельзя
обнулить. Новые классы и замена встроенных
классовых пассивок пока не поддерживаются; интерфейс не обещает обратного.

## 8. Применить изменения на сайт

1. Нажмите **Проверить изменения**. Сервер проверит данные и покажет справа,
   что будет использоваться после публикации. Это ещё ничего не сохраняет.
2. Нажмите **Сохранить черновик**. Черновик приватный, игроки его не видят.
3. Нажмите **Опубликовать** и подтвердите. Только теперь данные меняются на сайте.
4. Откройте Modern. Новые билды используют актуальный каталог; в уже открытом
   или сохранённом билде нажмите **Обновить текущий билд**, если хотите перейти
   на новую версию. Старые ссылки сохраняют свою версию расчёта.

Worker/D1 не ждут деплоя GitHub Pages: изменения каталога доступны после
публикации. В уже открытом сайте используйте **Билды → Обновить текущий билд**:
это запрашивает актуальную версию сразу. Автоматического пересчёта старого
билда нет — иначе сохранённые ссылки могли бы незаметно изменить результат.
Офлайн обновление невозможно. Номер версии показывает, какие данные используются.

Если сервер сообщил, что запись менялась в другой вкладке, не публикуйте
поверх вслепую. Скопируйте свои несохранённые тексты, заново откройте запись
и проверьте действующую версию. Ошибка сохранения сама поля не удаляет.

Для выхода нажмите `LOGOUT`. Для отмены ошибочной публикации есть
**История / откат**: восстановление создаёт новую версию, не стирает историю.
