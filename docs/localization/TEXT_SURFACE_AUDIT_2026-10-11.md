# Аудит текстовых поверхностей Modern и админки — 2026-10-11

## Что реально просканировано

Автоматически исследованы **31 исходный JavaScript-файл** в `modern/*.js` и `admin-api/public/*.js`. Статический анализатор `scripts/audit_localization_surfaces.py` ищет прямые присваивания видимого текста, подсказки, ARIA-подписи, подписи динамически созданных элементов и языковые условные операторы. Он дополнительно обнаруживает явные обращения к отсутствующим ключам `localization/ui.en.json`.

На исходном срезе версии 3.74 найдено **113 кандидатов** (не 113 подтверждённых ошибок). Они документированы в `localization/text-surface-audit-baseline.v1.json`. В ходе Modern 3.75 три подписи менеджера билдов переведены на именованные UI-ключи и редактируются в D1. Прочие находки — открытая инвентаризация. У каждой есть точное имя файла, тип, фрагмент и строка в JSON-отчёте.

## Как воспроизвести аудит

```bash
python3 scripts/audit_localization_surfaces.py --json > /tmp/text-audit.json
python3 scripts/audit_localization_surfaces.py --check
python3 -m unittest tests.test_text_surface_audit -v
```

`--json` содержит список всех кандидатов с номерами строк и флагом `newCandidates`.
`--check` завершится с ошибкой, если появится новая неразобранная строка или
статический ключ UI, которого нет в реестре. Для новых исключений нужен явный
пересмотр baseline, а не автоматическое добавление всего подряд.

## Границы достоверности

Это **инвентаризация исходных поверхностей, а не доказательство 100% покрытия**.
Эвристический анализ не выявляет все HTML-шаблоны, сообщения из сложных шаблонных
строк, генерируемые runtime-подписи и хранящиеся в D1 тексты. Он не проверяет
корректность смысла переводов на RU/EN/JP/TW. Архив Legacy исключён умышленно.

Для игрового расчёта независимым эталоном остаются актуальные игровые правила:
дифференциальные тесты Modern/Legacy обнаруживают регрессии, но **не доказывают**,
что обе версии точно повторяют текущую механику сервера. В Modern 3.75
числовые формулы не меняются; добавлен тест обратимости бонусов Гильдии на
одинаковых входных данных при переключении языков.

## Принцип ответственности

Опубликованные редакторские значения D1 остаются приоритетными; текст не
переименовывается на клиенте после публикации. Исправление названия предмета
должно проходить через существующего владельца каталога D1, а UI-текста —
через единый центр локализации. Изменения, которые влияют на характеристики,
требуют отдельной проверки расчётов и версионирования каталога.

### Приоритет дальнейшей работы

1. Высокий: динамические пользовательские статусы и модальные окна Modern.
2. Средний: доступность и предупреждения `aria-label` / `title` / `placeholder`.
3. Отдельный проект: локализация служебных экранов Cloudflare Admin без дублирования хранилищ.
