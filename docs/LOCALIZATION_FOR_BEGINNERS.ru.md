# Как переводить сайт на русский без терминала и Git-команд

Эта инструкция рассчитана на человека, который раньше не редактировал файлы проекта и не загружал обновления на GitHub.

Для перевода нужен только один файл:

`localization/translations.xlsx`

В нём 1 764 строки: весь современный интерфейс сайта и 1 617 игровых названий из Legacy 2.00. В таблице есть English, 日本語, 繁體中文 и отдельная русская колонка.

Сейчас сайт применяет заполненные переводы современного интерфейса, предметов и Souls в окнах поиска. Названия рас, классов и навыков тоже есть в таблице: их можно заполнить заранее, но подключение этих названий к основному калькулятору ещё предстоит. Сохранённая страница `/legacy/` остаётся музейной версией.

## Самое важное

Меняйте только жёлтый столбец **Русский — заполнять здесь**.

Не меняйте:

- имя файла `translations.xlsx`;
- имя листа `Переводы`;
- первую строку с заголовками;
- столбцы `Раздел`, `ID`, `Тип`, `Путь Legacy`, `English`, `日本語`, `繁體中文`.

Таблицу можно фильтровать и сортировать. Пустая русская ячейка не ломает сайт: для неё останется английский текст.

## Часть 1. Скачать таблицу

1. Откройте репозиторий: <https://github.com/bonaqu/Pandora-Saga-Simulator-remaked>.
2. Убедитесь, что выбрана ветка `bonaqu_projects`.
3. Откройте папку `localization`.
4. Нажмите файл `translations.xlsx`.
5. Нажмите кнопку **Download raw file** справа над файлом. Обычно у неё значок стрелки вниз.
6. Сохраните файл. Не переименовывайте его.

Прямая ссылка для скачивания актуальной таблицы:

<https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/raw/refs/heads/bonaqu_projects/localization/translations.xlsx>

## Часть 2. Заполнить русский перевод

1. Откройте `translations.xlsx` в Microsoft Excel.
   Если сверху написано «Защищённый просмотр», нажмите **Разрешить редактирование**. Если Excel не установлен, таблицу можно открыть в бесплатном LibreOffice Calc и сохранить в формате Excel `.xlsx`. Поддержка этого формата описана в [официальной справке LibreOffice](https://help.libreoffice.org/latest/en-GB/text/shared/guide/ms_user.html?DbPAR=CALC&System=WIN).
2. Откройте лист `Переводы`.
3. Найдите жёлтый столбец **Русский — заполнять здесь**. Это последний столбец справа.
4. Введите русский текст напротив нужной английской строки.
5. Чтобы найти предмет или навык, нажмите стрелку фильтра в заголовке `English` или нажмите `Ctrl+F`.
6. Чтобы оставить только нужный вид строк, используйте фильтр `Тип`. Например: `Предмет`, `Навык`, `Класс`, `Soul` или `Интерфейс сайта`.
7. Нажмите `Ctrl+S`.
8. Убедитесь, что файл остался в формате `.xlsx` и называется `translations.xlsx`.

Для строк интерфейса иногда встречаются части вида `{total}`, `{shown}`, `{level}`, `{ui}`. Скопируйте такую часть в русский перевод без изменений. Например:

- English: `{shown} of {total} compatible items`
- Русский: `Подходит: {shown} из {total}`

Не переводите текст внутри фигурных скобок и не удаляйте скобки.

## Часть 3. Загрузить таблицу на GitHub

1. Снова откройте папку `localization` в репозитории.
2. Нажмите **Add file**.
3. Нажмите **Upload files**.
4. Перетащите изменённый `translations.xlsx` в окно браузера.
5. GitHub должен показать, что файл `translations.xlsx` будет заменён.
6. В поле сообщения напишите, например: `Update Russian translations`.
7. Выберите **Commit directly to the bonaqu_projects branch**, если GitHub показывает такой выбор.
8. Нажмите **Commit changes**.

После этого ничего собирать на компьютере и ничего запускать в терминале не нужно.

## Часть 4. Проверить автоматическое обновление

1. Откройте вкладку **Actions** в репозитории.
2. Сверху появится запуск **Deploy Pandora Saga Simulator**.
3. Подождите, пока слева от него появится зелёная галочка. Обычно это занимает несколько минут.
4. Откройте сайт: <https://bonaqu.github.io/Pandora-Saga-Simulator-remaked/>.
5. Если появится сообщение **Доступна новая версия — Обновить** (или **New version available — Reload**), нажмите **Обновить / Reload**. Оно появляется и при изменении только таблицы. Если сообщения пока нет, обновите страницу, немного подождите; можно закрыть все вкладки сайта и открыть его заново.
6. Нажмите `RU` в переключателе языка интерфейса.
7. Проверьте изменённую строку. Переводы предметов и Souls используются в современных окнах поиска.

## Если появилась красная ошибка

Красный запуск означает, что новая таблица не опубликована. Уже работающий сайт при этом остаётся на предыдущей исправной версии.

Чаще всего причина одна из этих:

- изменён заголовок или служебный столбец;
- удалена строка;
- добавлена лишняя строка;
- изменён `ID`;
- в строке интерфейса потеряна часть `{total}` или другая часть в фигурных скобках;
- файл сохранён не как `.xlsx`;
- лист `Переводы` переименован.

Что делать:

1. Откройте красный запуск в **Actions**.
2. Откройте задачу `build`.
3. Найдите первый красный шаг и скопируйте его сообщение.
4. Пришлите мне ссылку на запуск или скриншот ошибки. Я найду конкретную строку.

## Безопасный первый тест

Для первого раза найдите через `Ctrl+F` значение `header.project` в столбце ID. В его жёлтой ячейке напишите свой перевод слова `Project`, например `О проекте`. Сохраните таблицу и загрузите её. После зелёного deploy включите RU и проверьте ссылку в верхней части сайта. Затем можно переводить игровые названия небольшими группами по 10–30 строк.

Перед каждой новой порцией переводов скачивайте последнюю таблицу с GitHub: так вы не затрёте уже загруженные переводы старой копией.

Исходные Legacy-формулы и игровые данные таблица не меняет. Она задаёт только отображаемый русский текст.
