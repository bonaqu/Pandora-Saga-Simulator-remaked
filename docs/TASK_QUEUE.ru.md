# Очередь разработки Pandora Saga Simulator Remaked

Обновлено 3 октября 2026. Переписка — требования и история, Git и опубликованные
файлы — доказательство результата. Новое пожелание добавляется сюда, а не отменяет
начатую работу. «Написано» не означает «опубликовано и проверено».

## Сейчас: довести интерфейс, затем продолжить функции

1. **Modern 3.04: доработка UI — на проверке, ещё не опубликована.**
   Из примера Hybrid C берём ясные секции, компактность, спокойные результаты и
   атмосферу Pandora. На ПК сохраняем широкое рабочее пространство, все ветки
   умений и результаты. Не копируем узкую картинку целиком, уровень 120 и LOG/FILE.
   В этот же блок входят персональные ошибки Level/STA/STR/AGI/DEX/SPR/INT,
   одинаковая высота подписей и полей BUFF, всплывающие JOB/SKILL с повторным
   нажатием для закрытия, удобный поиск на телефоне и две колонки выбора в JOB.
   План: [Hybrid C](superpowers/plans/2026-10-03-hybrid-c-composition.md).
2. **Приёмка этого UI-блока.** Полный CI, расчёты против Legacy, просмотр ПК и
   телефона, PR и публикация, затем проверка именно файлов рабочего сайта,
   авторизации и установленного приложения. До этого не считать UI законченным.
3. **Собственные условия изучения новых навыков — не закончены.** Сейчас новый
   активный/пассивный навык использует условие изучения существующего шаблона.
   Следующий блок: понятные условия по классу, уровню и веткам без копирования
   формул и без изменения старых навыков. План:
   [Custom skill learning](superpowers/plans/2026-10-03-custom-skill-learning.md).
4. **Новые классы и более широкие механики персонажа — не закончены.** Редактировать
   существующие классы уже можно; произвольно добавлять новые классы сверх 28 пока
   нельзя. Нужны совместимость сохранённых билдов, требований предметов, расчёта и
   сравнения. Не расширять число классов одним изменением лимита.
5. **Сверка с текущим сервером Weapons of Balance — продолжается.** Проверки
   Modern ↔ Legacy подтверждают работу сохранённого движка, а не автоматически
   все значения сегодняшнего сервера. Вводить подтверждённые исправления отдельно;
   не придумывать перевод, игровые числа и формулы. Максимум в симуляторе — 55,
   исходные 28 классов не скрываем из-за временных ограничений сервера.

## Ограничения, которые нельзя скрывать

- Для активных навыков редактируются название, описание, MP и время; симулятор
  не рассчитывает их боевой урон, ротацию или бой. Это отдельная будущая механика.
- Не каждый необычный исходный код эффекта безопасно превращать в произвольные
  числа. Неизвестный маркер показывается как ограничение, а не как выдуманный бонус.
- Смена рабочего каталога не должна незаметно переписывать старые билды: их
  закреплённые версии воспроизводимы; обновление текущего билда проверяется явно.
- Эмуляция телефона и браузерные тесты не заменяют проверку на каждом реальном
  устройстве и не доказывают идеальность всех размеров интерфейса.
- R2, платные функции и сервисы с требованием карты не используем.
