Editor capabilities and limitations

Единый центр переводов: интерфейс, навыки, умения, их требования, снаряжение, души, классы, расы и расчётные характеристики. Все четыре языка RU / EN / JP / TW можно редактировать в одной карточке. Поиск работает на четырёх языках; фильтр языка меняет только статус переводов и статистику. Отдельный игровой каталог ниже поддерживает 28 классов (включая прогрессию), 18 расовых пассивок, 178 активных и 33 пассивных навыка, экипировку и души. Новые игровые механики, классы и другие изменения за пределами допустимых правил ещё не поддерживаются. Изменение перевода не меняет расчёты или сохранённые билды.

How translations are stored

Утверждённые ранее переводы уже загружены в исходный каталог редактора. Новые публикации сохраняются в Cloudflare D1 с версиями; черновики и историю можно просматривать в закрытой админке. Modern больше не собирает переводы из Excel; загружать Excel для публикации новых переводов не нужно.

Каталог — единственный редактор для новых предметов, душ и умений: общий центр переводов показывает их опубликованные тексты и открывает здесь нужную карточку. Черновики каталога можно собрать и опубликовать одной версией без дублирования переводов.
