Возможности и границы редактора

Единый центр переводов: интерфейс, навыки, умения, их требования, снаряжение, души, классы, расы и расчётные характеристики на RU / EN / JP / TW. Отдельный игровой каталог ниже поддерживает 28 классов (включая прогрессию), 18 расовых пассивок, 178 активных и 33 пассивных навыка, экипировку и души. Новые игровые механики, классы и другие изменения за пределами допустимых правил ещё не поддерживаются. Изменение перевода не меняет расчёты или сохранённые билды.

Подсказка по источникам переводов

Утверждённые ранее переводы уже загружены в исходный каталог редактора. Новые публикации сохраняются в Cloudflare D1 с версиями; черновики и историю можно просматривать в закрытой админке. Modern больше не собирает переводы из Excel; загружать Excel для публикации новых переводов не нужно.

Редактор ниже изменяет игровые данные. Сохранённые черновики всех категорий можно собрать и опубликовать одной версией каталога.
