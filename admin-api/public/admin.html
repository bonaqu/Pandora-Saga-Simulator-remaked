Editor capabilities and limitations

Translate the interface, skills, requirements, equipment, Souls, classes, races and calculated values in one place. Edit RU / EN / JP / TW in the same card; search all four languages. The catalog also manages 28 classes, 18 racial passives, 178 active and 33 passive skills, equipment and Souls. New mechanics and classes outside supported rules are not yet available. Translating text never changes calculations or saved builds.

How translations are stored

Previously approved translations are already in the editor's baseline catalog. New publications are versioned in Cloudflare D1; drafts and edit history are available in the protected admin area. Modern no longer publishes translations from Excel files.

The catalog is the only editor for newly added equipment, Souls and skills. The translation center shows published texts and opens their catalog cards. Catalog drafts can be published as one revision without duplicating translation data.
